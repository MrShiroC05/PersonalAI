# Personal AI

Moblie Application นี้จัดทำเพื่อเป็น Project ส่งอาจารย์ในรายวิชาเพียงเท่านั้น แต่ก็เป็นการศึกษานอกห้องเรียนเกี่ยวกับการเรียกใช้ AI มาเป็น Chat model และยังสามารถทำให้ AI บันทึกวันนัดหมายของเราได้

## System

### Server

เนื่องจากเราเรียกใช้ Key API จากภายนอก จึงจำเป็นต้องมี server มาลองรับเพื่อความปลอดภัยของผู้ใช้งานและตัว server เอง
ระบบของเราจะส่งข้อความผ่าน JSON เพื่อไปพูดคุยกับ Gemini ผ่าน server ดังนั้น ทางฝั่ง Moblie application จึงทำหน้าเพียงติดต่อกับผู้ใช้งานและนำข้อความไปส่งยัง server แล้วค่อยให้ server ติดต่อกับ gemini ผ่าน API key อีกที
หลังจากที่ได้คำตอบจาก gemini แล้วจึงส่งคำตอบจาก serveer ไปที่ Moblie application

### Feature

1. สามารถเพิ่ม ลบ เปลี่ยนสถานะโดยผู้ใช้เอง
2. พูดคุยกับ AI
3. บันทึกนัดผ่านการพูดคุยกับ AI
4. AI สามารถที่จะอ่านความชอบ, ความสนใจ จากการที่เราบันทักไว้ใน momory
5. AI สามารถที่จะอ่านและวิเคราะจัดสรรวันนัดหมายของเราได้
